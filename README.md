# Іменники в українському тексті

Лабораторна робота з комп'ютерної лінгвістики. Програма знаходить іменники в українському тексті, підсвічує їх, будує частотність початкових форм і виконує морфологічний розбір обраного іменника: рід, число, відмінок, відміну, групу, абстрактність та збірність.

## Структура проєкту

```
lab_nlp_uk/
├── app.py              інтерфейс Streamlit
├── nlp_core/           лінгвістичне ядро без залежності від інтерфейсу
├── data/               тестові тексти трьох стилів
├── tests/test_nlp.py   модульні тести pytest
├── requirements.txt
└── README.md
```

## Встановлення

```
pip install -r requirements.txt
```

## Запуск

Запуск застосунку з кореневої папки проєкту:

```
streamlit run app.py
```

Запуск тестів:

```
pytest -v
```

## Як користуватися

1. Оберіть один із тестових текстів або вставте власний українською мовою (від 3 слів до 20 000 символів).
2. Натисніть «Аналізувати текст».
3. На вкладках переглядайте підсвітку, список іменників, частотність, морфологічний розбір і правила.
4. На вкладці «Іменники» введіть номер речення, щоб побачити іменники лише в ньому. Номер має бути від 1 до кількості речень.

## Лінгвістичні правила

Рід визначається за початковою формою. Відміна визначається за родом і закінченням леми: I відміна — жіночий рід на -а, -я та чоловічий на -а, -я; II відміна — чоловічий на приголосний, -ь, -й, -о та середній на -о, -е, -я; III відміна — жіночий на -ь і решта жіночих та середній на -мя. Група визначається лише для I і II відмін. Абстрактність визначається за суфіксами (-ість, -ство, -ння, -ття, -ота, -изм, -ізм, -ація). Збірність визначається за словником збірних іменників. Повний опис є на вкладці «Правила».

## Обмеження

Омонімія вирішується лише за частотністю розбору без контексту. Абстрактність за суфіксами не покриває всіх слів. Збірність покривається лише словником.
